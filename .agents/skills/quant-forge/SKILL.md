# 量化研究与开发规范（QuantForge）

详细知识笔记：本仓库 `docs/`（8 篇自包含知识笔记 + 索引）。

在量化项目中干任何活之前，先过一遍本规则。核心总纲：
**可复现（路径/样本/命令/输出可交接）、可证伪（预设否定条件）、可审计（主张有源、失败留痕）、不过度承诺（绩效如实标注阶段：回测/模拟/实盘）；回测 → 模拟盘 → 实盘三级流水线，晋级过门槛、人工批准、小资金灰度；先保证活着，再谈赚钱；所有回测结论默认有罪（过拟合/未来函数/幸存者偏差），直至样本外检验无罪。**

## 一、六段工作流（每个量化任务的骨架）

研究假设 → 数据质量 → LLM 结构化信号 → 策略规则 → 事件驱动回测 → 风险控制

1. **研究假设先行**：任何交易想法先写成六要素假设卡——对象（资产+样本文件路径）、触发条件、观察窗口、对照基准（买入持有）、评价指标、否定条件（拆"不支持"与"证据不足"，如 trade_count<2）。**看过回测结果后再改假设，研究作废（防 HARKing）**。
2. **数据质量**：三层数据架构（实时/快照/固定样本）；回退必须显性标注 source，禁止旧快照冒充实时数据；清洗原则"能解释的转换才做，缺失记 None 不填 0"；K 线唯一键 `exchange+symbol+interval+openTime`。
3. **LLM 信号**：规则基线先行，LLM 只做解释层；输出收敛到固定枚举 + 有界数值（confidence 0–100）、证据溯源、reviewFlags；LLM 失败时回退规则基线并记录 note。
4. **策略规则卡**：研究语言必须降为明确规则——触发/仓位/退出/冷却/失效/停止/成本/成交假设；规则卡不写预期收益。
5. **事件驱动回测**：逐 K 线推进，先结算挂单→写入历史→策略产出 OrderIntent→风控+撮合→记权益；保留 trades/pending/risk_rejections 三类审计记录。
6. **风控前置**：下单前 + 挂单成交前双拦截；风控路径在回测/模拟/实盘三阶段完全同构，实盘执行适配器只是替换撮合层。

## 二、安全边界（硬性红线，任何情况下不越界）

- **交易阶段分级**：execution_mode 显式三档 research（回测）/ paper（模拟盘）/ live（实盘），由配置 + 人工批准开启；晋级须过门槛（样本外通过、模拟盘达标、风控与 Kill Switch 演练、人工书面批准）；live 小资金灰度起步；任何模式下不得绕过风控下单。详见 `docs/08-模拟盘与实盘工程.md`。
- **表述红线**：绩效必须标注阶段（回测/模拟/实盘），禁止跨阶段暗示；不得把回测收益表述为实盘收益预期；短样本年化必须注明样本长度与公式；`confidence` 不是上涨概率。
- **防幻觉**：LLM 摘要中每个数字必须可追溯到输入字段，否则标记 FABRICATED_OR_UNSUPPORTED。
- **防前视偏差**：
  - 检查代码中的 `shift(-N)`、`np.roll(..., -N)`、`future_*` 字段；
  - 信号时点与成交时点分开（信号依赖收盘价则下一根 K 线才可成交）；
  - 数据按 `event_time / published_at / available_at` 可见时间对齐（Point-in-Time）；
  - 当日盘中决策不得使用当日收盘/最高/最低价（信号闪烁）；指标宁可迟滞确认，绝不重绘。
- **防数据窥探/过拟合**：
  - 记录全部试验（含失败），报告必须写 num_trials / search_space / selection_rule / discard 摘要；
  - 严格三分数据 训练 60% / 验证 20% / 测试 20%，测试集只跑一次，未通过样本外的策略一律作废；
  - 参数敏感度检验：好策略参数邻域是"高原"，过拟合是"孤针"（MA20 赚、MA19/21 巨亏即作废）；
  - 回测必须包含已退市股票（防幸存者偏差）；
  - 用滚动回测 + Walk-forward + 参数扰动 + 成本敏感性验证；任一 fragile/overfit 即降级为"研究线索"。
  - 参数越少越好。

## 三、市场规则约束（写交易/回测代码必须遵守）

A股（按目标市场替换，Web3 另见课程原文）：
- **T+1**：当日买入不可当日卖出；卖出逻辑必须校验可卖持仓（available 而非 position）。
- **涨跌停**：主板 ±10%、创业板/科创板 ±20%、北交所 ±30%；触板即流动性归零（涨停买不进、跌停卖不出），下单前必须检查是否触板。
- **成本**：印花税卖出单边 0.05%、佣金约万 2.5~3（最低 5 元）双向，往返 ≈0.11%；**预测收益 − 交易成本 < 阈值则不下单**；高频在 A股 几乎不可行。
- **滑点**：不得假设按收盘价足额成交；大单用 TWAP/VWAP 拆单；远离流动性极差标的；零成本回测必须标注"简化口径，成本未建模"。

## 四、仓位与风控哲学

- **凯利公式** f* = (bp−q)/b：下注过重即使正期望也会破产（60% 胜率 + 50% 仓位，100 把后本金趋近 0）。回测胜率是历史值，真实 p 不可知，**必须用半凯利（×0.5 或 ×0.3）**，波动率高时进一步降仓。
- **几何平均 > 算术平均**：亏 50% 需涨 100% 回本，回撤是复利头号死敌。优先级：**降低最大回撤 > 提高年化收益**；活得久才是最高的阿尔法。
- **风控三件套**：硬止损（无条件执行）、跨资产分散、冗余资金（永不满仓）。

## 五、"永远不要做"清单（源自 LTCM / 光大乌龙指 / 闪崩 / GME）

1. 永远不要高杠杆（危机时所有相关性趋近 1，分散化瞬间失效；正态假设低估肥尾）。
2. 永远不要无资金校验、无单量上限、无 Kill Switch 地发单（每套下单系统必须有：可用资金校验、单笔/单日限额、一键停止、重试次数上限与去重）。
3. 极端行情永远不要用市价单（流动性真空时成交在极端价位）；只用限价单或对手价−保护比例；盘口异常即停机。
4. 永远不要做空亏损无上限的资产（GME 逼空：空头比例 >100% + 伽马挤压）。
5. 不要把止损单挂在拥挤的整数关口（会被插针扫损）；用程序内软止损。
6. 不要相信"回测高收益 = 实盘赚钱"；必须做极端行情压力测试，并设护栏（如当日亏损 >5% 强制平仓停机）。

## 六、指标与报告规范

- **MDD** 基于权益曲线峰谷复算（非价格跌幅）；Calmar = 总收益% / |MDD%|（须声明口径）；Sharpe 必须绑定 periods_per_year / total_trades / num_trials。
- 权益 equity = cash + position × close；净收益必须扣 fee / slippage / funding。
- 报告可追溯：主张账本（claim / evidence_layer / source_path / decision / limitation），claim_traceability、metric_attribution、limitation_coverage 三率均须 1.0 才发布。
- 报告必须包含数据来源、样本区间、试验次数与选择规则、局限性声明。
- 快照双写（history/ 归档 + 当前指针 + manifest.json 完整性校验），支持"报告→数据集→指针→历史归档→清单"逆向追溯。

## 七、经典策略速查（适用条件与陷阱）

- **趋势跟踪/海龟**（唐奇安突破 + 2ATR 止损）：依赖肥尾大行情，胜率 30~40%、盈亏比高；死于震荡市；均线滞后是特性不是 bug。
- **网格**：只适用于震荡市 + 不会退市标的（ETF/蓝筹）；死于单边下跌（满仓套牢）与单边上涨（提前卖飞）。
- **动量/轮动**：看相对强弱，适合 ETF 周频轮动；个股动量有天地板风险；掉出排名即卖出，别和趋势谈恋爱。
- 策略与市况错配是最大风险源。

## 八、AI 委托纪律（对自己的要求）

- 拆多轮干活：限定范围 → 构造反例 → 运行窄口测试 → 输出命令+退出码+关键输出 → 声明剩余边界。
- 未实际运行不得称"测试通过"；不改只读/vendor 目录；不为追收益而调参。
