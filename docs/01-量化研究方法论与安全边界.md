# 量化研究方法论与安全边界

## 一、六段核心工作流

完整研究链条：**研究假设 → 数据质量 → LLM 结构化信号 → 策略规则 → 事件驱动回测 → 风险控制**。

- 顺序不可倒置：未写清假设禁止回测；数据未经质量验证禁止进入指标；信号未过污染门禁禁止进入策略；规则未冻结成本/成交假设禁止解读收益；绩效未过稳健性审计禁止比较排名。
- 四类主体权责：AI 编程工具只做工程执行（改代码、跑测试、留日志）；LLM 只做解释层（组织已有证据）；量化验证只证明样本内结果；人是唯一决策主体，风险责任不可转移给工具。
- 任何结论必须能拆回四层：事实（输入中真实存在）、解释（基于事实的谨慎说明）、检验（可复算的指标）、决定（由人做出的取舍）。拆不回去的输出只是候选，不是结论。

## 二、六要素假设卡（防 HARKing）

运行任何回测前，必须书面填写六要素，缺一项禁止启动：

1. **对象**：资产 + 数据文件完整路径（保证可复现）。
2. **触发条件**：明确事件，如"3 日均线上穿 7 日均线"。
3. **观察窗口**：至反向信号或样本结束。
4. **对照基准**：默认买入持有，须手算基准值核对。
5. **评价指标**：策略收益、基准收益、最大回撤、交易次数，事先固定。
6. **否定条件**：拆分两类——"不支持"（如策略收益≤基准）与"证据不足"（如 trade_count<2），优先判不支持。

**防 HARKing 红线**：禁止先看回测结果再反推规则；禁止看到输出后新增/修改指标；改参数、换指标必须另开新假设卡；辅助观测数据不能把"不支持"翻转为"有观测价值"。

判读三档制：支持 / 不支持 / 证据不足。解释段只允许这三档，行动段只允许继续观测、新建假设卡、终止测试。

## 三、研究 ≠ 实盘红线

- 系统能力上直接移除真实执行入口：不连真实账户、不存钱包授权、不提交订单；执行能力枚举仅允许 `none` / `simulation_only`，`real_order` 一律 blocked，人工确认也不能绕过。
- 动作三层：允许（读样本、算指标、生成摘要，自动运行）；需审批（改参数、调风险阈值、接新数据源，须留修改人/原因/影响/回退方案）；禁止（一切实盘动作）。
- 禁止 LLM 修改仓位上限、关闭风险规则、覆盖回测失败；模型解释与风控结果冲突时，保留可复算的规则结果。
- 风控前置：敞口 E=|q·P|/V ≤ 上限 L 才允许开仓；止损触发 D=P_t/P_0−1 ≤ −S；风控拦截在成交模拟之前，不在事后补说明。

## 四、三大污染检查清单

**防前视（决策时不可见的信息不得参与特征、提示词、参数、样本筛选）**：

- 代码扫描 `shift(-N)`、`roll(..., -N)`、`future_`、`next_`、`tomorrow_` 字段；
- 信号依赖本根收盘价则下一根成交，禁止同根先看后成；
- 财报/链上/新闻按"可见时间"（published_at / available_at）对齐而非业务日期；
- 用当前存续标的回测历史 = 幸存者偏差，须含退市/下架样本。

**防过拟合**：参数空间事先冻结；训练/测试边界冻结，不得反复改；同根 K 线禁止先知收盘再按收盘成交；插值价禁止触发交易。

**防数据窥探**：全部试验（含失败）写入试验日志；报告必须披露 num_trials、search_space、selection_rule、失败版本摘要；n 次尝试至少一次偶然命中概率 1−0.95^n，只展示赢家必然夸大证据。

## 五、滚动回测要求

单次回测不能下结论，须通过审计层级：连续窗口稳定性 → 多策略对比（保留失败者作基线，收益榜/回撤榜/权衡榜三榜并列）→ Walk-forward（训练段选参、样本外验收，报告 best_params、OOS 收益、num_trials、DSR、overfit_warning）→ CPCV 多条样本外路径（fragile 即降级）→ PBO 与参数扰动 → 成本预设敏感性（teaching / realistic / perp 三档）。任一环节脆弱即整体降级为"研究线索"。

## 六、表述红线

禁用："策略有效""可实盘""建议买入""风险可控""收益稳定""市场证明"。

替换为："在固定样本 X 与参数 Y 下，回测输出为 Z，不代表真实账户收益/未来收益/投资建议；未覆盖滑点、资金费率、订单簿深度"。

confidence 非上涨概率，仅是输出强度。收益/回撤/年化/胜率数字必须同时带样本区间、参数口径、计算路径、成本假设与不可外推边界。
