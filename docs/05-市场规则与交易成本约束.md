# 市场规则与交易成本约束

## 一、T+1 与底仓 T+0（A股）

- T+1：当日买入股票次日才能卖。当日无法纠错，风险暴露至少 4 小时并承担隔夜风险。
- 变通方案"底仓 T+0"：持有昨日以前的底仓，日内"买入新仓 + 卖出等量旧仓"，收盘持仓数不变，赚取日内差价。本质是库存管理，不是真 T+0。
- 代码约束：卖出前必须校验**可卖数量**（available，剔除当日买入）而非总持仓；日内策略需维护底仓账本（新旧仓分开记账）。

## 二、涨跌停与磁吸效应

| 板块 | 涨跌幅限制 |
|---|---|
| 主板 | ±10% |
| 创业板/科创板 | ±20% |
| 北交所 | ±30% |

- 涨停买不进、跌停卖不出：**流动性归零**，止损单在跌停时无法成交。
- 磁吸效应：接近 ±8~9% 时，持筹者惜售、抢筹者涌入，价格被"吸"向板；跌向 −8% 时恐慌盘加速撞向跌停。
- 代码约束：下单前检查最新价距涨跌停价的空间；触板或临近触板（如剩余空间 <1%）时禁止追单/止损市价单；回测撮合必须模拟"跌停不可卖、涨停不可买"。

## 三、交易成本的具体数值

- 印花税：卖出单边 0.05%。
- 佣金：约万分之 2.5~3，双向收取，单笔最低 5 元。
- 过户费：极低可忽略。
- **一次完整往返 ≈ 0.11%**。若每天做一次 T，一年 250 个交易日，摩擦成本 0.11% × 250 ≈ **27.5%**——频繁交易本身即可亏掉近三成本金。
- 代码约束：信号过滤 `if (预测收益 − 往返成本) < 阈值(如 0.2%): 不交易`。

## 四、滑点与冲击成本

- 显性税费之外，隐性成本滑点常更致命：想买 10.00 元，成交均价 10.02 元。
- 大单拆分算法：
  - **TWAP**（时间加权）：按时间均匀拆单。
  - **VWAP**（成交量加权）：按市场成交量分布拆单，跟随市场节奏。
  - 例：100 万股拆成 1000 笔小单，数十秒一笔，把滑点压至接近零。
- 回测必须假设滑点与冲击成本，不能假设"按收盘价足额成交"；资金量越大或标的越小时，**流动性风险 > 市场风险**。远离日成交额仅数百万的僵尸股。

## 五、衍生品杠杆与强平

- 期货：保证金制度自带约 5~10 倍杠杆；亏损触及维持保证金即被要求追加，未追加则强制平仓；穿仓可倒欠资金。
- 期权：买方最大亏损为权利金，卖方（义务方）亏损理论上无限；Delta 表示标的价格敏感度，Gamma 是 Delta 的变化率；做市商对冲行为可放大价格运动（伽马挤压）。
- 杠杆的本质：剥夺"等待黎明"的权利——方向可能最终正确，但中途被强平出局。

## 六、综合编程红线

下单前置校验清单：可用资金 ≥ 订单金额；可卖数量 ≥ 卖出数量；价格未触板；单笔/单日限额内；重试有次数上限；异常行情（价差、盘口深度异常）触发时暂停交易。

极端行情禁用市价单，改用限价单或"对手价 − 2%"的保护性限价单。
