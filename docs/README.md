## 总纲

- 可复现（路径/样本/命令/输出可交接）、可证伪（预设否定条件）、可审计（主张有源、失败留痕）、不过度承诺（绩效如实标注阶段：回测/模拟/实盘）。
- 回测 → 模拟盘 → 实盘三级流水线，晋级过门槛、人工批准、小资金灰度；风控路径三阶段同构，任何模式不得绕过。
- 先保证活着，再谈赚钱；所有回测结论默认有罪（过拟合/未来函数/幸存者偏差），直至样本外检验无罪。
